AI 연결

Windows용 PDF 편집기 1.1.0부터 PDFEditorCLI.exe가 함께 설치됩니다. Claude Desktop, Claude Code처럼 MCP를 지원하는 AI 도우미에 연결하면, AI가 PC에 있는 PDF를 읽고 형광펜·밑줄·메모·도형·도장을 넣고 쪽을 정리한 뒤 결과를 그림으로 확인합니다. 저장한 파일은 PDF 편집기에서 그대로 열어 고칠 수 있습니다.

  • 원본은 덮어쓰지 않고 새 파일로 저장합니다.
  • 이 프로그램은 인터넷에 연결하지 않습니다. 다만 AI 도우미가 읽은 문서 내용은 그 AI 서비스로 전달되며, 그 서비스의 방침을 따릅니다.
  • Android용에는 이 기능이 없습니다.

Claude Desktop에 연결

  1. PDF 편집기 1.1.0 이상을 설치합니다.
  2. 시작 메뉴에서 ‘명령 프롬프트’를 열고 아래 한 줄을 실행합니다. 
    "%LOCALAPPDATA%\Programs\PDFEditor\PDFEditorCLI.exe" connect claude-desktop
  3. Claude Desktop을 완전히 종료한 뒤(알림 영역 아이콘에서 종료) 다시 실행합니다. 도구 목록에 pdf-editor가 보이면 연결된 것입니다.

Claude의 다른 설정은 그대로 두고, 바꾸기 전 설정 파일을 claude_desktop_config.json.bak으로 남깁니다. 연결을 지우려면 같은 명령에 connect --remove claude-desktop을 씁니다. 휴대용(zip)은 압축을 푼 폴더의 PDFEditorCLI.exe로 같은 명령을 실행합니다.

Claude Code와 그 밖의 프로그램

아래 명령이 붙여 넣을 내용을 출력합니다.

"%LOCALAPPDATA%\Programs\PDFEditor\PDFEditorCLI.exe" connect --print
  • Claude Code: 출력된 claude mcp add … 한 줄을 실행합니다.
  • Cursor 등 다른 MCP 프로그램: 출력된 JSON을 그 프로그램의 MCP 설정(mcpServers)에 넣습니다.
  • MCP를 쓰지 않는 도구는 PDFEditorCLI.exe 명령을 직접 실행합니다. 모든 명령은 결과를 JSON으로 출력합니다.

이렇게 시킬 수 있습니다

  • “문서\계약서.pdf에서 ‘위약금’이 나오는 곳을 모두 형광펜으로 칠하고 계약서_표시.pdf로 저장해 줘.”
  • “이 PDF 3쪽 오른쪽 여백에 요약을 메모로 적어 줘.”
  • “스캔본.pdf에서 빈 쪽을 지우고 2쪽을 오른쪽으로 돌려 줘.”

파일은 전체 경로로 알려 주는 것이 가장 확실합니다.

도구와 명령

아래는 AI 도구를 직접 설정하거나 스크립트를 짜는 분을 위한 참고 자료입니다. 같은 내용이 설치 폴더의 PDFEditorCLI-GUIDE.txt에 들어 있습니다.

좌표

  • 쪽 좌표(page points): 화면에 보이는 쪽(회전 적용) 기준, 왼쪽 위가 원점, x는 오른쪽, y는 아래로 증가, 단위 pt(1/72인치). text·find·annotations의 bbox, 변경 JSON의 at·box·boxes·from·to·arrow_to·paths가 이 좌표입니다. render PNG도 같은 방향이며 픽셀 = pt × scale입니다.
  • PDF 좌표(PDF user space): PDF 파일 자체의 좌표, 회전 전 쪽의 왼쪽 아래가 원점, y는 위로 증가. pdf_rect, 주석의 rect, 변경 JSON에서 직접 주는 rect·quads·line·ink.strokes·callout.arrow가 이 좌표입니다.
  • 쪽 번호는 1부터 셉니다.

명령(도구) 목록

괄호 안은 MCP 도구 이름입니다.

info (pdf_info)

쪽 수, 쪽마다 보이는 크기(pt)·회전·주석 수.

PDFEditorCLI.exe info 안내문.pdf

{"ok": true, "page_count": 1, "annotation_count": 0, "pages": [{"page": 1, "width": 594.96, "height": 841.92, "rotation": 0, "cropbox": [0.0, 0.0, 594.96, 841.92], "annotations": 0}]}

text (pdf_text)

텍스트 줄과 위치. --pages "1,3-5"로 쪽을 고릅니다.

PDFEditorCLI.exe text 안내문.pdf --pages 1

{"ok": true, "pages": [{"page": 1, "lines": [{"text": "가을 학기 독서 모임 안내", "bbox": [63.0, 74.28, 258.41, 98.37], "pdf_rect": [63.0, 743.55, 258.41, 767.64]}]}]}

find (pdf_find)

문구 찾기. 띄어쓰기와 대소문자를 무시합니다(한국어 PDF는 추출한 글자에 띄어쓰기가 빠지는 일이 많습니다). 한 번 나온 것마다 줄 하나에 상자 하나를 돌려주고, 같은 쪽 안에서 위→아래 순서로 occurrence 번호를 붙입니다.

PDFEditorCLI.exe find 안내문.pdf "중앙도서관 세미나실"

{"ok": true, "count": 1, "matches": [{"page": 1, "occurrence": 1, "bboxes": [[390.75, 198.31, 481.25, 210.92]], "pdf_rects": [[390.75, 631.0, 481.25, 643.61]]}]}

annotations (pdf_annotations)

기존 주석: id, type, page, bbox, rect, contents, 주요 스타일. 수정·삭제할 때 이 id를 씁니다.

PDFEditorCLI.exe annotations 결과.pdf

{"ok": true, "count": 1, "annotations": [{"id": "obj:8:0", "type": "highlight", "page": 1, "bbox": [390.75, 198.31, 481.25, 210.92], "rect": [390.75, 631.0, 481.25, 643.61], "contents": "", "style": {"fill_color": "#FCDA51", "opacity": 1.0}, "editable": true}]}

id는 그 파일 안에서만 유효합니다. 저장할 때 PDF 개체 번호가 다시 매겨지므로, 새로 저장한 파일을 고칠 때는 annotations로 id를 다시 읽습니다.

render (pdf_render)

한 쪽을 주석까지 포함해 PNG로 그립니다. 명령줄은 --out이 필요하고, MCP는 그림을 응답에 넣으며 out을 주면 파일로도 저장합니다. --scale 기본값은 명령줄 2(144dpi), MCP 1.5입니다.

PDFEditorCLI.exe render 결과.pdf --page 1 --scale 1.5 --out 1쪽.png

{"ok": true, "page": 1, "scale": 1.5, "width_px": 893, "height_px": 1263, "out": "C:\\작업\\1쪽.png"}

apply (pdf_apply)

변경 JSON을 적용해 새 PDF로 저장합니다.

PDFEditorCLI.exe apply 안내문.pdf --changes 변경.json --out 결과.pdf
PDFEditorCLI.exe apply 안내문.pdf --changes-json "[{\"type\":\"highlight\",\"page\":1,\"text\":\"독서 모임\"}]" --out 결과.pdf
PDFEditorCLI.exe apply 안내문.pdf --changes 변경.json --in-place

{"ok": true, "out": "C:\\작업\\결과.pdf", "in_place": false, "page_ops": 0, "created": [{"index": 0, "type": "highlight", "id": "obj:8:0", "page": 1}], "updated": [], "deleted": [], "page_count": 1}
  • --out이 원본과 같은 파일이면 거부합니다. 원본에 저장하려면 --out 대신 --in-place를 줍니다.
  • --author 이름: 새 주석의 작성자. 주지 않으면 앱 환경 설정의 작성자를 씁니다.
  • 메모(타자기·텍스트 상자·콜아웃)를 만들면 created에 넣은 글꼴과 내장 여부(fonts)가 나옵니다.
  • 적용 뒤 render로 쪽을 그려 위치와 글자를 확인하는 것을 권장합니다.

mcp

MCP 서버를 실행합니다. AI 프로그램이 직접 실행하므로 사람이 실행할 일은 없습니다. 표준 출력에는 프로토콜 메시지만 쓰고 기록은 표준 오류로 보냅니다.

connect

위 "연결하기" 참조. connect --print, connect claude-desktop, connect --remove claude-desktop.

변경 JSON

파일은 UTF-8입니다. 두 가지 형태가 있습니다.

[ {변경}, {변경} ]

{ "pages": [ {쪽 작업}, ... ], "changes": [ {변경}, ... ] }

객체 형태에서는 쪽 작업을 먼저 순서대로 하고, 그 결과 문서에 주석 변경을 적용합니다. 각 쪽 작업의 쪽 번호는 앞 작업까지 반영된 문서 기준이고, changes의 쪽 번호는 모든 쪽 작업이 끝난 문서 기준입니다. 상대 경로(file, image)는 변경 파일이 있는 폴더 기준입니다(--changes-json은 현재 폴더 기준). 중간에 하나라도 실패하면 아무 파일도 쓰지 않습니다.

공통 필드

필드 뜻
op create(기본), update, delete
type 아래 종류. 별칭: rectangle→square, ellipse→circle, pen→ink, freetext→textbox
page 쪽 번호(만들 때 필수)
contents 메모 글(메모 종류는 필수, 다른 주석은 선택: 주석 내용으로 저장)
style 스타일(선택). 주지 않은 값은 종류별 기본값
id update·delete의 대상(annotations의 id)

style 키: text_color, border_color, fill_color(#RRGGBB 또는 null), border_width(pt), opacity(0–1), font_size(pt), font_family, line_spacing(배수), dash(선 길이 배열, 예 [3, 2]).

종류별 기본 스타일은 앱과 같습니다: 형광펜 #FCDA51, 밑줄 #D32F2F, 취소선 #FF0000, 메모 글자 #2196F3 13.5pt, 사각형 #66BB6A 1pt, 타원 #EF5350 2pt, 화살표 #D32F2F 2pt, 선 #42A5F5 2pt, 펜 #42A5F5 1pt.

형광펜·밑줄·취소선 (highlight, underline, strikeout)

위치는 셋 중 하나로 줍니다.

  • text: 그 쪽에서 찾을 문구(띄어쓰기·대소문자 무시). 두 번 이상 나오면 occurrence(1부터, 위→아래)가 필요합니다. 없으면 실패하며 다른 위치로 대신하지 않습니다. 여러 줄에 걸치면 줄마다 한 영역이 됩니다.
  • boxes: 쪽 좌표 상자 목록 [[x0, y0, x1, y1], ...].
  • rect + quads: PDF 좌표. quads는 영역마다 8개 수 [x1,y1, x2,y2, x3,y3, x4,y4](왼쪽 위, 오른쪽 위, 왼쪽 아래, 오른쪽 아래).
{"type": "highlight", "page": 1, "text": "중앙도서관 세미나실"}
{"type": "underline", "page": 2, "text": "마감", "occurrence": 2}
{"type": "highlight", "page": 1, "boxes": [[63, 300, 200, 312]], "style": {"fill_color": "#80DEEA", "opacity": 0.6}}

타자기 (typewriter)

테두리 없는 글. at: 왼쪽 위 쪽 좌표 [x, y], width: 폭(pt). width를 빼면 오른쪽 여백까지 쓰고 긴 줄은 자동으로 나눕니다. 높이는 줄 수에 맞춰 정해집니다. "wrap": true면 폭에 맞게 앱의 줄바꿈 규칙으로 줄을 나눕니다(없으면 contents의 줄바꿈만 씁니다). box(쪽 좌표)나 rect(PDF 좌표)도 쓸 수 있습니다.

{"type": "typewriter", "page": 1, "at": [330, 70], "width": 220, "contents": "장소: 중앙도서관 3층", "wrap": true}

텍스트 상자 (textbox)

테두리·바탕이 있는 상자. box: 쪽 좌표 [x0, y0, x1, y1](또는 rect). 글이 넘치면 아래로 늘어납니다.

{"type": "textbox", "page": 1, "box": [330, 110, 560, 160], "contents": "발제 순서는 첫 모임에서 정합니다.", "style": {"border_color": "#2196F3"}}

콜아웃 (callout)

화살표가 달린 상자. box(상자), contents, arrow_to: 화살표 끝 쪽 좌표 [x, y](또는 PDF 좌표 "callout": {"arrow": [x, y]}).

{"type": "callout", "page": 1, "box": [330, 260, 560, 300], "contents": "격주 진행", "arrow_to": [300, 215]}

사각형·타원 (square, circle)

box(쪽 좌표) 또는 rect(PDF 좌표).

{"type": "square", "page": 1, "box": [60, 70, 262, 102]}
{"type": "circle", "page": 1, "box": [385, 192, 488, 216], "style": {"border_width": 1.5}}

선·화살표 (line, arrow)

from, to: 쪽 좌표. 화살표 머리는 to 쪽입니다. PDF 좌표로는 "line": [x0, y0, x1, y1]. 끝 모양은 "line_ends": ["None", "ClosedArrow"]처럼 줄 수 있습니다(None, Square, Circle, Diamond, OpenArrow, ClosedArrow, Butt, ROpenArrow, RClosedArrow, Slash).

{"type": "arrow", "page": 1, "from": [440, 165], "to": [440, 192]}

펜 (ink)

paths: 획 목록, 획마다 쪽 좌표 점 두 개 이상 [[x, y], [x, y], ...]. PDF 좌표로는 "ink": {"strokes": [[x1, y1, x2, y2, ...]]}.

{"type": "ink", "page": 1, "paths": [[[500, 250], [520, 240], [540, 260]]]}

스탬프 (stamp)

원천은 하나만: text(짧은 글자 스탬프, 둥근 테두리; color 기본 #D32F2F, font_size 기본 18), image(PNG·JPEG 경로, transparent_white: 흰 바탕 투명), crop({"file": "다른.pdf", "page": 3, "box": [x0, y0, x1, y1], "dpi": 300}: 다른 PDF 쪽의 일부를 그림으로). 위치는 at(+ width 또는 height, 비율 유지) 또는 box. name으로 스탬프 이름을 줄 수 있습니다.

{"type": "stamp", "page": 1, "text": "확인", "at": [480, 760]}
{"type": "stamp", "page": 2, "image": "서명.png", "at": [400, 700], "width": 120}

수정·삭제

update는 바꿀 필드만 줍니다. 위치 단축 필드(at, box, from/to, paths, arrow_to)도 쓸 수 있고, 타자기의 at에 width가 없으면 원래 폭을 유지합니다. 종류와 쪽은 바꿀 수 없습니다.

{"op": "update", "id": "obj:11:0", "contents": "고친 메모", "style": {"text_color": "#D32F2F"}}
{"op": "update", "id": "obj:14:0", "box": [380, 190, 490, 220]}
{"op": "delete", "id": "obj:16:0"}

쪽 작업 (pages)

op 필드
rotate pages, by(시계 방향, 90의 배수, 기본 90)
delete pages(모든 쪽은 지울 수 없음)
move pages + before/after(쪽 번호) 또는 at("start"/"end")
insert_blank 위치(before/after/at, 기본 맨 끝), count(1–100), size("like" 기준 쪽과 같게(기본), A4, A4-landscape, A3, letter, 4:3, 16:9, [w, h])
duplicate pages(바로 뒤에 복제)
import file(다른 PDF), pages(기본 전체), subset(all/odd/even), 위치(기본 맨 끝), annotations(copy 기본/none/flatten), fit(true면 기준 쪽 크기에 맞춤), bookmarks(related 기본/none/all), root_bookmark(true면 파일 이름, 문자열이면 그 제목)
scale_content pages, scale(0.05–20) + anchor(center 기본, top-left, top, top-right, left, right, bottom-left, bottom, bottom-right) 또는 box(쪽 좌표 영역에 비율 유지로 맞춤). 쪽 크기는 그대로, 주석도 함께 움직임("annotations": false면 제자리). 필기 여백을 만들 때 씁니다

pages 값은 "3", "2-4,7"처럼 씁니다.

{
  "pages": [
    {"op": "import", "file": "부록.pdf", "pages": "1-2", "at": "end"},
    {"op": "insert_blank", "after": 1, "size": "A4"},
    {"op": "scale_content", "pages": "1", "scale": 0.8, "anchor": "top-left"}
  ],
  "changes": [
    {"type": "typewriter", "page": 1, "at": [480, 40], "width": 110, "contents": "여백 메모", "wrap": true}
  ]
}

제한

  • 회전된 쪽(90°·180°·270°)에는 at·box로 메모(타자기·텍스트 상자·콜아웃)를 만들 수 없습니다. 편집 엔진이 메모 글자를 쪽 회전 없이 그리므로 글자가 옆으로 눕습니다. 먼저 rotate로 쪽을 0°로 돌리거나, PDF 좌표 rect로 직접 지정합니다. 형광펜·도형·선은 회전된 쪽에서도 됩니다.
  • 쪽 본문 개체(글자·그림) 자체를 옮기거나 지우는 기능(content_edits)과 벡터 잘라내기 스탬프(crop의 vector)는 이 프로그램에 없습니다.
  • 암호가 걸린 PDF는 열지 않습니다.
  • 서식 있는 메모(PDF-XChange에서 글꼴·색을 부분적으로 바꾼 메모)는 형식을 그대로 지킬 수 없으면 수정을 거부합니다. 이때 원본은 바뀌지 않습니다.
