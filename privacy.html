개인정보처리방침

시행일: 2026년 11월 25일

PDF 편집기(이하 “앱”)는 기기 안에서만 동작하는 PDF 편집 도구입니다. Windows용과 Android용에 적용되며, Android용 선택 엔진은 아래의 설치 절차를 사용합니다.

수집하는 정보

앱은 이용자의 개인정보를 수집하지 않으며, 열거나 편집한 문서를 외부로 전송하지 않습니다. 계정 가입, 광고, 분석 도구가 없습니다.

기기 안에서 다루는 정보

  • PDF 문서: 이용자가 직접 고른 문서만 읽습니다. 편집하는 동안 문서 사본과 편집 내용이 앱 전용 저장 공간에 보관되고, 저장할 때 이용자가 지정한 위치에 기록됩니다.
  • 설정과 최근 파일 목록: 글꼴, 작성자 이름, 최근에 연 파일 목록이 기기에 저장됩니다.
  • 오류 기록: 앱에서 오류가 나면 원인 파악을 위한 기록이 기기에 남습니다. 이 기록은 기기 밖으로 전송되지 않습니다.

기기 설정에서 앱 데이터를 지우거나 앱과 설정 폴더를 삭제하면 위 정보는 모두 삭제됩니다.

권한

  • 인터넷(Android): 편집 화면은 기기 내부에서 통신합니다. 선택 엔진 설치를 누르면 GitHub Releases에 접속해 APK를 다운로드합니다. 이때 GitHub 및 다운로드 서버에 IP 주소 등 통상적인 요청 정보가 전달됩니다. 변환은 기기에서 실행합니다.
  • 저장소 전체 접근 권한은 요청하지 않습니다. 문서는 시스템 파일 선택 화면에서 이용자가 고른 것만 엽니다.
  • 선택 엔진 설치(Android): 이용자가 PPT 변환 엔진 설치를 선택하면 시스템 설치 화면을 엽니다. 설치 여부는 이용자가 확인합니다.

아동

앱은 아동을 대상으로 하지 않으며 아동의 개인정보를 수집하지 않습니다.

변경

방침이 바뀌면 이 페이지에 시행일과 함께 게시합니다.
